# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in StemGolf-VocalWave, please report it responsibly by emailing security@example.com instead of using the public issue tracker.

Please include the following details:
- Description of the vulnerability
- Steps to reproduce (if applicable)
- Potential impact
- Suggested fix (if you have one)

We appreciate your help in keeping this project secure and will work to address reported vulnerabilities promptly.

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.x     | :white_check_mark: |
| < 1.0   | :x:                |

## Security Updates

We recommend keeping your installation up to date to receive the latest security patches. Check the [Releases](https://github.com/EGZeelie/StemGolf-VocalWave/releases) page regularly for updates.
