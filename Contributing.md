## How Are Contributors Recognized?

Contributors are recognized in multiple ways:

1. **This File** - Listed in CONTRIBUTORS.md with role and link
2. **Commit History** - Your commits appear in the git log forever
3. **Release Notes** - Featured in release announcements
4. **GitHub Stats** - Visible on the repository's contributor graph

## Adding Yourself

When your PR is merged, you'll automatically be:
- Listed in the GitHub contributor graph
- Credited in commit history

To be added to this file, simply mention it in your PR or open an issue asking to be listed.

## Contribution Types We Recognize

We value all types of contributions:

- 💻 **Code** - Features, bug fixes, refactoring
- 📚 **Documentation** - README updates, guides, examples, translations
- 🐛 **Bug Reports** - Detailed issue reports with reproducible steps
- 💡 **Ideas** - Feature suggestions and design discussions
- 🔍 **Code Review** - Reviewing PRs and providing feedback
- 🎨 **Design** - UI/UX improvements, mockups, accessibility
- ⚡ **Performance** - Optimization and benchmarking
- 🧪 **Testing** - Test coverage, edge case discovery
- 🌍 **Localization** - Translations and region-specific improvements
- 📢 **Community** - Help in discussions, mentoring new contributors
